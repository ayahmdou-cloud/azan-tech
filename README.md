# أذان تيك — Azan Tech

مواقيت مسجدك والأذان في بيتك، أينما كنت. — Hayat Tech · Ayman AHMADOU

نسخة الويب: البطاقات (أول تشغيل)، الشاشة الرئيسية، الإعدادات، القبلة.
كل الإعدادات والملفات الصوتية بتنحفظ بالجهاز نفسه (localStorage و IndexedDB)، ما في سيرفر.

| الملف | الدور |
|---|---|
| `setup.html` + `ui.js` | البطاقات والإعدادات (نفس الأقسام) |
| `screen.html` | الشاشة الرئيسية (من أذان البيت 3.0) |
| `qibla.html` | القبلة: بوصلة + خريطة + كاميرا |
| `core.js` | المحرّك: المواقيت، المكتبة، الأذان، الـ API المحلي للشاشة |
| `praytimes.js` | حساب المواقيت (12 طريقة) والقبلة |
